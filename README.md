# cojoin-info

Static site for CoJoin, served by GitHub Pages at https://andrew-v1.github.io/cojoin-info/

- `index.html` — landing page (support link, privacy link)
- `invite/index.html` — where invite links land when the app isn't installed
- `PRIVACY.md` — privacy policy (rendered by Pages at /PRIVACY.html; also linked from the app)

Publish: create the repo `andrew-v1/cojoin-info` on GitHub, push `main`, then
Settings → Pages → Source: *Deploy from a branch*, branch `main`, folder `/ (root)`.
